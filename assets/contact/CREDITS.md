# Contact artwork

`creation-touch-reference.jpg` is the original image supplied by the user for the contact composition, retained as the source reference.

`pixel-touch.svg` is a code-drawn pixel pointing hand with a transparent background, off-white fill and stepped monochrome edges. It replaces the pointer previously clipped from the JPEG.

`creation-hand-halftone.png` is an imagegen edit of that reference: background extraction and black-and-white halftone style transfer, using the existing David sculpture screenshot as the rendering reference. This replaces the previous hand-traced clipping path.

The classical motif references **Michelangelo, The Creation of Adam**. [Original artwork reference](https://commons.wikimedia.org/wiki/File:Michelangelo_-_Creation_of_Adam_(hand_crop).jpg).

The source JPEG is unchanged. Depth and title layering are applied in the browser.

Edit brief: preserve the original pointing gesture and five-finger anatomy; isolate the hand on transparent alpha, including clean negative spaces between fingers; match David's silver monochrome, deep shadows and fine diagonal stipple. Omit the fresco wall, warm colours, pixel pointer, text, frames and extra objects from the hand asset.
